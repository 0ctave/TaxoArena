Standing rules the backfill adopted (for the correction pass to keep):
- Values are copied, never computed; `sources` names the file and commit for every one.
- Chips verbatim from the ledger; a qualified PASS keeps its qualification; UNDETERMINED rows are state UNDETERMINED.
- Every CORRECTED / SUPERSEDED / RESTATED / FLAG / CI ADDED insertion the ledger row carries is a dated entry in `brackets`; the last bracket wins.
- `script.sha16` = sha256 of the file at the named commit (LF), first 16 hex; a script absent at the registration commit carries the sha at its first commit, named as such.
- Free checks with no script of record say so and point at the output file.
- Line numbers carry `program_lines_as_of`; the `heading` and `outcome_heading` are the anchors to grep.

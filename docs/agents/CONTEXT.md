## 1. What this project is

A pre-registered test programme for an LLM-as-judge arena over a domain taxonomy, prepared for publication (thesis + paper + blog). The chain: build a taxonomy on the TRAIN side of a corpus → route held-out (EVAL) questions to its cells → rank models exactly where a key or checker exists → judge with one frozen recipe (STACK-v2) where it does not → fit per cell (question-clustered Bradley-Terry, agreement widener, key-tie decline) → publish boards, anchor-level profiles with intervals, tiers, bands, and a router's undominated set per cell. [FRAMING OF RECORD 2026-09-27, the author's adoption ("You can start", relayed by the orchestrator), recorded by the registrar (docs/judge_v2_program.md L21435-L21457 (section "## Author's decision 2026-09-27 (recorded by the registrar; zero calls; insertion only) — the framing of recor ..."; _as_of the commit that writes it, parent 5effe96, re-grepped); plan Amendment 25; texts docs/agents/plans/2026-09-26_framing_of_record.md and 2026-09-27_research_plan_rev2.md, A1-A4): "Cell-conditional evaluation". CENTRAL QUESTION: "For a fixed roster, a corpus split content-closed under CK-CLOSE, and a fixed verification instrument named per claim (an answer key, an executed checker, or one frozen judge recipe with its reference policy stated): when does evaluating per cell change which model an evaluator should use, or which pairwise comparison it may trust, compared with one pooled leaderboard? What does that cost, and which answers survive a second embedder, a second tree draw and a second corpus? Cells are declared labels for the arena, and are read by a TRAIN-only embedding taxonomy where labels are missing." SUB-QUESTIONS: SQ1 USE, SQ2 TRUST, SQ3 TAXONOMY, SQ4 PRICE, SQ5 INVARIANCE; SCOPE S1-S5 (declared arena cells; verification fidelity only; a split word on every object; recipes never joined; closed lines stay closed). r8 and the p2dca judged family are HISTORY, NEVER EVIDENCE ([P-FAM], docs/reviews/RULING_w0_p2dca_family.md; docs/judge_v2_program.md L21459-L21504 (section "## Registrar's record 2026-09-27 (insertion only; zero calls; nothing run) — the two Wave-0 RULINGS: (1) the a ..."; _as_of the commit that writes it, parent 5effe96, re-grepped)). ## 4. Standing rules (violations are incidents)

1. **The split is the coherence of the paper.** Construction, labelling and rubric induction never see EVAL questions. An artefact derived from a judged question at judgment time (the reference solve, a checklist) is allowed; induction over the reserved split is not. The TRAIN-ONLY guard refuses judging a tree with eval members.
2. **Register before you run.** Criteria, predictions and falsifiers go into `docs/judge_v2_program.md` (append at the END) and are committed BEFORE any code or call. UNDETERMINED is a registered outcome. Every judged script is dry-run at zero calls, then a 12-match pilot read by the truncation guard (refuse above 5% unparsed on the deciding subset), then the run, then the analysis that refuses partial caches.
3. **Correct by insertion only.** Never delete or rewrite a recorded sentence; append a dated bracket `[CORRECTED YYYY-MM-DD by TEST: ...]`; the last bracket wins. Chips carry the narrative's qualifier; a rule adopted mid-session applies backward in the same commit.
4. **Check the data object before reading strata into it** (the x20 cache has zero verdicts on the 66 original pairs; the sparse-board incident). Name the key denominator every time. A null must preserve what the question conditions on (within-anchor, not across).
5. **Budget rule:** ask before any judged run above 4,000 arena matches (~8k calls). Temperature is OMITTED on every judge call (plan Amendment 1 D2). The deployed judge is grok-4-1-fast-non-reasoning; the reference is the cached grok-4-1-fast-reasoning solve; cap 8192; dual order, TIE on flip.
6. **Never** modify `snapshots_frozen.db`; never commit `config/application.yml`, `.env`, `.gitignore`; never use `seeds = [...]`; never join mmlu_pro↔eval by `question_text` (join by the OPTIONS key); exclude `Meta-Llama-3-70B-Instruct`; restore `frozen_triples_*_MAIN.json` from HEAD after any MAIN construction.
7. **One construction at a time**, never while anything reads the pool; label-free unless the build is arena-bound; back up output dirs.

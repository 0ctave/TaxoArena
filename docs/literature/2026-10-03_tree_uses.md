The consequence: the tree's distinctive assets are **stability (P1), filing discipline (P2), a conservative split
gate (P6) and a free abstention/OOS signal (P4, P5)**. Its partition quality is ordinary. Uses that need a

## 2. Online evolution of the tree

**Record.** EPOCH-GROWTH is a *drafted* queue item (machine, 3-3.5 h, 0 calls; rank "defer"; blocker "n = 3
tree-pairs is a band, not a test"; unregistered). The "newcomer placement" work in the record (PLACEMENT-STEPS,
newcomer_placement) places new *models* on the arena board, not new *queries*; no query-level incremental work
exists.

**Operations** (each mapped to a shown property):
1. *File*: every new item goes to its flat leaf (P2), with margin and OOS score.
2. *Buffer*: items that are low-margin or OOS (P4, P5) go to a per-region buffer, not into a leaf.
3. *Refit means*: in-leaf items update the leaf mean online (sequential k-means; the topology is fixed). P7 shows
   re-estimation on fixed topology is cheap and can help; it was label-using, so the label-free online version
   is untested.
4. *Propose a split*: when a buffer (or a leaf) exceeds mcs 55, run the construction's split rule on it.
5. *Certify*: accept only if the site null certifies (P6). Prediction from the record: a new *domain*
   (declared-strength structure) passes at depth-1 sizes; within-anchor 2-way splits will mostly not (0 of 60),
   so the tree grows by new top-level cells, rarely by refinement. IFEval's anchor-free root did not clear the
   bar (0.02111 < 0.025), so some new domains will enter as one cell.
6. *Merge / retire*: a leaf with no traffic for W windows is retired (id tombstoned, never reused); two leaves
   whose means converge below the separation bar are merged into the older id.

**Triggers.** OOS rate above its GATE-calibrated FPR level; buffer size >= mcs; occupancy chi-square drift; a
scheduled full rebuild as the reference (construction is deterministic at a fixed split, so the batch tree on
the accumulated data is a well-defined target).

**Stability vs plasticity.** Downstream routing tables and reports key on cell ids. Rules: ids are immutable; [CORRECTED 2026-10-03 by ONLINE-REPLAY-LOMO (registrar; POSTRUN b739bd46 W-3): only with FROZEN leaf means: online mean refit moved 9.25% (BBH replay) and 3.04% (MMLU_PRO_LB) of in-member addresses; F-OL fired; docs/judge_v2_program.md L24021-L24029; the frozen-means design is registered as ONLINE-STAGE2, L24054-L24068]
a split creates child ids and keeps the parent id as an alias for reporting roll-up; merges map to the older id;
every update logs an id-map. Measure *address churn* (share of a fixed probe set whose cell changes per update)
and *decision churn* (share whose routed model changes); only the second costs anything downstream.

**Prior work.** BIRCH (Zhang, Ramakrishnan, Livny, SIGMOD 1996, DOI 10.1145/233269.233324) [S]; CluStream
(Aggarwal, Han, Wang, Yu, VLDB 2003, pp. 81-92) [S]; DenStream (Cao, Ester, Qian, Zhou, SDM 2006, pp. 328-339)
[S] (outlier micro-clusters ≈ our buffer); online k-means (Liberty, Sriharsha, Sviridenko 2014,
arXiv:1412.5721) [V]; PERCH (arXiv:1704.01858) [V] and Grinch (Monath et al., KDD 2019, arXiv:2001.00076) [V]
(rotate/graft); Rajagopalan et al., ICML 2021 [V] (order invariance); online level-wise HAC (Monath, Zaheer,
McCallum, KDD 2023) [S]; EvoTaxo (arXiv:2603.19711) [V] (propose-then-validate edits). None of them gates a
split with a calibrated null; that combination is the candidate contribution.

**Minimal zero-call simulation (O-LOSO).** Leave-one-source-out replay on the v2 union split, CPU only, no
build: take the AF-U per-member trees UNION-AF-ROUTE already built (`experiment_results/archv2/union_af_route/AF-U/`
{bbh, gpqa, ifeval, math, mmlu_pro_lb, musr}; untracked, backed up to E:). Each member was built on its own TRAIN
only, so a held-out member never touched the other five trees. (i) Start from the graft of 5 members;
stream the 6th member's TRAIN then EVAL items in a fixed shuffled order. (ii) Readouts: OOS AUROC of the held-out
member against the 5 in-members' EVAL (the "new domain" trigger, on capability text for the first time);
buffer purity; whether k-means on the buffer at the member's own leaf count matches that member's batch tree
(NMI / filing precision against the batch arm); address churn on in-member EVAL (should be 0 if the old leaves
are untouched). (iii) Within-member arm: replay TRAIN in 5 orders with online mean refit vs batch means; report
P_fl difference and churn. Certification of the proposed split (step 5) is a site null: machine time under rule
7, so it is a second stage, not part of the zero-build simulation. Value H for the title (an agent's query stream
is open-world); risk: six sources is a small n of "new domains", IFEval is a known one-cell case, and OOS on
capability text may be weak. Register before code (standard flow).

## 4. What this note does NOT support
- That any use needs *this* tree rather than k-means at matched k (N1). Every use above should carry a k-means arm.
- A discovered or certified fine taxonomy; any cell name as a claim.
- OOS or drift detection on real traffic, on capability text, or on tree cells (pending OOS-TREE-CELLS).
- Label-free routing at declared-label level, or tool routing at all.
- Label-noise detection (FF2 undetermined) or a label-free gain from mean refit (FF1 used labels).
- Invariance of any cell id across embedders, prompts or bars.

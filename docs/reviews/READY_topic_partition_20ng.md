## Defects (ranked)

1. **HIGH — the I1 smoke is not a gate (chain L558-568).** After `build ag_news_smoke_s42` the chain logs "SMOKE readouts: built yes/NO / pool recorded ... / trickle ran ..." and proceeds to T1 whatever it read. Registration I1: if Design N fails in the smoke, the study falls back to Design S "by a registrar bracket BEFORE T1". An unattended chain would instead embed 16,921 documents into embeddings_cache.db and attempt T1 on an unproven path. Fix (chain, after L562): refuse unless the smoke log carries `Snapshot ID:`, `[POOL] recorded p` and `Total Queries:` — e.g. `grep -q 'Snapshot ID:' "$sb" && grep -q '\[POOL\] recorded p' "$sb" && grep -q 'Total Queries:' "$sb" || { log "SMOKE FAILED (Design N unproven): refusing to start T1; the registrar decides Design S (I1)"; exit 1; }`. **Code before launch.**
2. **MEDIUM — `construction_started()` (chain L391) counts `[SPLIT-CLOSURE]` as a construction iteration.** That line is logged by finishSplit BEFORE "Phase 1: Precomputing Embeddings" (af_clean_s42.build.out L30 vs the Engine start at L33; h9_embed_gemma.log died in the embedding phase after the split line), so an embedding-phase failure in a run that printed it is classed "construction started; not retried": the relaunch rule is vacuous for exactly the runs it exists for. On 20NG the line never prints (norm-v1 dedup removes every stem-key duplicate, closure 0); on the ag_news smoke (a verbatim copy that keeps duplicates) it can. Fix: `construction_started() { grep -q 'DAG DIAGNOSTICS\|Snapshot ID:' "$1" 2>/dev/null; }`. **Code before launch.**
3. **MEDIUM — the pin covers 7 of the 12 tables of mmlu_pro_dataset_cache_v2.db** (chain L302-304 copies the review 2026-09-20 section 3 list verbatim), while the registered acceptance rule reads "every mmlu_pro_dataset_cache_v2.db table UNCHANGED in n and sha". Fix (chain L302-304): add `("twenty_newsgroups","id"), ("arc","id"), ("mmlu_original","id"), ("active_reserved_pool","only_row"), ("sqlite_sequence","name")`. **Code before launch** (the acceptance rule is this READY's pin).

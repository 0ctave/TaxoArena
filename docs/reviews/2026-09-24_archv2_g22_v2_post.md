## The D9 ruling (question 1)

**The convention.**
- The registration says "EVERY target lies inside its simulated central (1 - 0.05 / T) interval" (L15219, L15348). It names neither the endpoint rule nor the quantile type.
- The instrument declared both before the data:
  - `covered()` returns `ql <= target <= qh` (inclusive).
  - `report.quantiles` returns `np.quantile(v, q)` (linear, Hyndman-Fan type 7).
  - Both are present at f1192e6 (2026-09-24 02:52:59); `git log -S "ql <= target <= qh"` names f1192e6 and 4381e4b.
- The READY reviews (5dfc825, f8c2979) passed this code without comment. So the convention was declared in code, never in words.
- **Inclusive is the only coherent reading for count targets.** Four H2 targets are 0 with q_lo 0.00 (f_loao_wrong, f_loao_wrong_est, u_loao_wrong, u_loao_wrong_est). A strict rule fails every zero-count target whose support starts at 0, so under the strict rule part B would FAIL on 5 of 12 targets, 4 of them trivially.
- I rule the inclusive convention BINDING as coded.

**The quantile type** (`scratchpad/g22v2/d9_flip.py`):
- The printed statistics allow 9 tail configurations, (n below 3, n equal to 3):
  - (0, 7), (0, 8), (0, 9)
  - (1, 5), (1, 6), (1, 7)
  - (2, 3), (2, 4), (2, 5)
- Under the INCLUSIVE rule, types 1, 4, 5, 6, 7, 8 and 9 ALL cover the target in every configuration. Types 1 and 7 give q_lo = 3 exactly; the others give 2.08-3.00.
- Under a STRICT rule, types 1 and 7 fail in every configuration. Types 4-6, 8 and 9 fail only when fewer than 2 values lie below 3.
- **No quantile type flips the verdict under the rule as coded.**

**Robust or knife-edge: KNIFE-EDGE, on one target.**
- Bootstrap over replicates: P(flip) = 0.022 / 0.041 / 0.080 / 0.081 / 0.145 / 0.149 / 0.258 across the configurations. Resampling the tail's own counts gives the same range.
- Predictive for a fresh R = 1,000 (Dirichlet(counts + 0.5)): 0.045-0.244. The central configurations give about 0.08-0.17.
- **The population reading.**
  - The count of replicates at or below 3 is 5-9 of 1,000. Its Clopper-Pearson lower end is 0.00163 at 5 and 0.0022 at 6, against the tail 0.00208, so it is unresolved only at N = 5.
  - The count below 3 is 0-2, giving F(2) <= 0.002 < 0.00208 at the point estimate.
  - So at infinite R the lower end converges to 3 = the target. The verdict is decided by inclusivity, not only by Monte-Carlo noise.
